# Explora Colombia 🇨🇴 - Tablero Interactivo de Departamentos

Tablero web interactivo desarrollado en **React 19 + TypeScript + Vite** para explorar y consultar la información geográfica, demográfica y territorial de los departamentos de Colombia en tiempo real.

---

## 🛠️ Cómo Ejecutar el Proyecto

1. Abrir la terminal y situarse en la carpeta del proyecto:

   ```bash
   cd "Parcial 2 Frontend"
   ```

2. Instalar dependencias (si no se han instalado):

   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:

   ```bash
   npm run dev
   ```

4. Compilar para producción y validar TypeScript:

   ```bash
   npm run build
   ```

5. Ejecutar análisis de código (Linter):
   ```bash
   npm run lint
   ```
